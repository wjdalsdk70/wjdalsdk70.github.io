## Welcome

This is an example blog post. You can create new posts by adding markdown files to the `content/posts` directory.

## Creating a New Post

To create a new post:

1. Create a new `.md` file in the `content/posts` directory
2. Add front matter at the top of the file
3. Write your content in Markdown

### Front Matter

The front matter should include:

- `title`: The post title
- `description`: A short description
- `date`: Publication date
- `categories`: Array of categories
- `tags`: Array of tags
- `author`: Author name (optional)
- `pin`: Set to `true` to pin the post (optional)

## Markdown Support

This blog supports:

- **Bold** and *italic* text
- Code blocks with syntax highlighting
- Lists
- Links and images
- And much more!
